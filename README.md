# Goutam Chaudhary — Portfolio

React + Vite responsive portfolio inspired by the supplied reference.

## Features
- Dark/light theme toggle with smooth transition
- Oversized hero typography and hanging draggable ID card
- Pulling the card stretches the lanyard; release springs it back
- Alternating project image/content layout
- Company experience and academic background cards
- Animated circular orbit of design tools
- Compact contact footer and responsive mobile layout

## Run locally
```bash
npm install
npm run dev
npm run build
```

Replace the portrait and project image placeholders with final portfolio assets before publishing. Verify contact details and project descriptions.
